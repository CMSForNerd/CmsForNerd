# 📋 CmsForNerd Release Notes and Version History

Changelog and release notes for CmsForNerd v4.

---

## 🚀 Version 4.3.0
* **PHP 8.4 Architecture:** Property hooks, constructor property promotion, strict typing.
* **Zero-Global Design:** Replaced `$GLOBALS` with `CmsContext` and `Registry`.
* **Diátaxis User Manual:** Added local installation manual covering WSL2 AlmaLinux 10 and Podman.
* **Glassmorphism & AMP:** Consolidated stylesheets (`style.css` and `amp.css`) with dual-view rendering.
