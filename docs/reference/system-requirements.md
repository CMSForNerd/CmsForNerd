# 📋 System Requirements and Runtime Specifications

Environment specifications for running **CmsForNerd v4.3.0**.

---

## 🐘 Requirements Matrix

* **PHP Binary:** PHP 8.4.0+ (supports property hooks and readonly classes).
* **Extensions:** `mbstring`, `json`, `openssl`, `zip`, `curl` (optional: `apcu`).
* **Web Servers:** Nginx 1.20+, Apache 2.4+, LiteSpeed, IIS 10+, or PHP built-in CLI server.
* **Operating Systems:** Linux (Ubuntu/Debian/AlmaLinux/RHEL), Windows 10/11, macOS 13+.
