# 🛠️ Automated SEO, Sitemaps, and Structured Data Generation

CmsForNerd programmatically scans page routes and generates search engine discovery files.

---

## 🗺️ Execution

Run the SEO generator script:
```bash
php tools/generate-seo-files.php
```

Updates: `sitemap.xml`, `sitemap.txt`, `rss.xml`, `ror.xml`, and `schema-org.json`.
