# ⚙️ Installation Guide (v4.0.0)

Please refer to the main [Installation Guide](../docs/INSTALLATION.md) for detailed instructions on setting up the CmsForNerd laboratory.

## Quick Start (PHP 8.4+)

1. **Clone the repo:** `git clone https://github.com/CMSForNerd/CmsForNerd.git`
2. **Install dependencies:** `composer install`
3. **Verify setup:** `composer lab-check`
4. **Configure theme:** Edit `includes/global-control.inc.php` if necessary.
